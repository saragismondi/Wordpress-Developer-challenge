Classic theme for the AgroNews agriculture news portal.

== Description ==

AgroNews is a classic (non block) theme with no build step: the CSS and the
JavaScript it ships are the ones the browser downloads.

The front page is composed of independent blocks, each one with its own query
and its own template part under template-parts/:

* Featured: 5 stories from a configurable category.
* Latest: the 10 newest stories.
* By section: 3 categories, 4 stories each.
* Most read: 6 stories ranked by the an_views meta.

Block categories and the market quotes bar are configured by the companion
plugin, AgroNews Home. The theme renders correctly without it.
